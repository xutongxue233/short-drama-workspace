# 素材库

素材库保留生成过程中的图片、视频和音频；资产库继续承载项目确认、锁定的创作标准。两者不共享审批动作。

- `MaterialLibrary`：按项目查看素材、类型 / 保存状态筛选、历史素材补存、下载重试。
- `MaterialCard` / `MaterialDialog`：联系表卡片与独立大图、视频、音频预览。
- `MaterialMedia`：本地缩略图与主动打开的远程预览，媒体失败时显示明确提示。
- `MaterialActions`：本地文件下载，远程或失败素材保存到工作台。
- `materialUtils`：跨项目条目收集、生成时间排序、安全预览地址、大小和日期格式化。

工作台传入 `remote` 时，数据来自 `/api/projects/:id/materials`，类型、状态与关键词在服务端筛选，每页 24 条，由“加载更多素材”继续读取。项目下拉列表只需要项目摘要，不依赖整个工作区的素材数组。未启用 `remote` 的嵌入预览与组件测试继续读取 `Project.materials`，兼容旧项目缺少该字段；始终保留每个素材记录，不按资产名或 URL 去重。

列表打开期间每 2 秒读取首页及当前预览所在页（没有预览时读取最后加载页），最多两页；页面隐藏后暂停轮询。保存与补存完成后立即读取相关页，更新保存数量和预览。首页条目或筛选结果总数变化会清除后续页，避免新增或删除素材导致偏移分页出现缺口；用户可继续加载。切换项目或筛选条件会取消旧请求，即使服务端迟到响应也不会覆盖新视图。读取失败保留已加载内容并提供对应页的重试入口。

所有写操作由应用层传入的 `Action` 处理，以共享串行请求、刷新状态和错误反馈。媒体文件使用 `/api/media/:id/file`，添加 `?download=1` 触发文件下载。列表不预加载远程素材；用户主动打开预览后才读取远程地址，原始签名 URL 不展示在页面上。

全局入口通过 `initialProjectId` 默认选择当前项目，无有效默认项目时选中第一个项目；用户可切换项目，不混合展示多个项目的素材。项目被移除后回落到有效项目，无项目时显示空状态。`projectId` 用于嵌入的单项目视图，指定项目不存在时显示明确空状态，不回落到其他项目。

切换项目会重置搜索、类型及保存状态筛选并关闭预览。补存、重试保存等操作始终使用所选项目路径；正在制作的项目需先暂停才能补存历史素材。卡片省略已由项目选择表达的重复项目名，保留保存状态、错误与重试入口。
