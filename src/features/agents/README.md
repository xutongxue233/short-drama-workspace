# Agent 管理模块

外部页面从 `features/agents` 导入 `AgentCenter`。此模块管理全局创作成员的配置；项目内邀请与运行状态由工作区负责。

- `AgentCenter.tsx`：搜索、启用状态与成员类型筛选、项目参与计数、新增和维护入口。
- `AgentCard.tsx`：纯展示组件，通过回调通知启停、编辑、复制与删除操作，并区分内置和自定义成员。
- `AgentEditor.tsx`：新增、编辑、复制共用的表单，支持名称、职责、颜色、系统提示词、服务绑定、模型覆盖及技能绑定。
- `DeleteAgentDialog.tsx`：删除自定义成员的二次确认及失败重试，服务端负责最终引用校验。
- `agentConfig.ts`：内置成员标识、默认字段、颜色预设与避免同名的复制名称。
- `agentIcons.ts`：成员职责图标映射。
- `agents.css`：成员页面样式；通用管理布局复用 `components/settings/settings.css`。

`state` 和 `mutate` 由应用壳传入，不在此模块建立第二份全局工作区状态。模型选择复用模型模块公开导出的 `ModelPicker`。保存失败保留表单草稿并在弹窗显示错误，保存期间不能关闭弹窗；未保存的修改由公共 `Dialog` 保护。

新增及复制使用 `POST /agents`，编辑和启停使用 `PATCH /agents/:id`，删除使用 `DELETE /agents/:id`。必填的名称、职责和系统提示词去除前后空格后校验；字段上限与接口保持一致。复制需要确认后才创建，内置成员不可删除，参与项目或有历史引用的自定义成员应停用。项目参与数仅作为提示，不据此决定是否允许删除。

自定义成员启用后可在项目中邀请参与讨论，需要绑定可用的文本服务；固定制作流程的节点仍由内置成员执行。

表单接收工作区技能列表，每位成员最多绑定 8 个技能。新建与复制发送完整 `skillIds`，复制继承原成员的绑定；编辑只有在绑定改变时才发送该字段，避免无关配置维护被已有失效引用阻塞。停用技能仍可保留绑定，失效绑定可在表单中解除，已启用的绑定技能由服务端用于聊天和制作任务。
